# Kadam — Твой шаг к работе

ИИ-платформа занятости для Казахстана и Кыргызстана. Помогает **соискателям** находить работу, **работодателям** — кандидатов, а **государству** — управлять рынком труда и госпрограммами.

Продакшен-платформа: React-фронтенд, нативный Supabase бэкенд (auth + PostgreSQL + RLS) и детерминированное «ИИ-ядро» на клиенте.

## Роли

| Роль | Для кого | Возможности |
|---|---|---|
| **Работник** | Соискатель | ИИ-подбор вакансий с % совпадения, редактор резюме, генерация сопроводительных писем, тренажёр собеседования, чат-ассистент «Айла», трекер откликов |
| **Работодатель** | Компания | Воронка найма, ИИ-скрининг кандидатов с объяснением решений, генерация карточки вакансии, HR-ассистент |
| **Администратор** | Гос. орган | Панель занятости, аналитика рынка (recharts), программы и активные меры, модерация контента |

Демо-вход — через карточки ролей на лендинге (выбирает случайное имя из списка).

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # продакшен-сборка в dist/
npm run lint      # oxlint
```

## Продакшен: Supabase

Приложение поддерживает два режима: **демо** (все данные — моковые, в браузере) и **продакшен** (реальные аккаунты и данные в Supabase). Режим определяется наличием env-переменных.

1. **Схема БД**: выполните `supabase/schema.sql` целиком в *Supabase → SQL Editor* (таблицы, политики RLS, триггер создания профиля, сид-данные: 8 резюме, 20 вакансий).
2. **Переменные окружения**: задайте `VITE_SUPABASE_URL=https://<project-ref>.supabase.co` и `VITE_SUPABASE_ANON_KEY` в Cloudflare (Settings → Variables) и в локальном `.env` (см. `.env.example`). `VITE_`-переменные попадают в сборку, поэтому после их изменения нужен новый деплой.
3. **Первый администратор**: после регистрации через UI выполните в SQL Editor:
   ```sql
   update public.profiles set role = 'admin' where email = 'ваша@почта.kz';
   ```
   Админ-аккаунты не создаются с лендинга (доступ выдаётся вручную).

Данные защищены Row Level Security: соискатель видит и меняет только свои отклики и резюме, работодатель — только свои вакансии. Publishable-ключ не является секретом; `service_role` нигде не используется.

## Структура

- `src/lib/ai.js` — ИИ-ядро: матчинг навыков (с синонимами), fit-анализ, резюме, письма, разбор пробелов, сценарии вопросов, чат-ответы, скрининг для найма, генератор описаний вакансий.
- `src/data/` — реалистичные данные рынка труда КЗ/КР (вакансии, кандидаты, аналитика, госпрограммы).
- `src/components/ui.jsx` — переиспользуемый UI-кит.
- `src/views/` — `Landing`, `Shell` (оболочка) и три роли: `worker/`, `employer/`, `admin/`.
- `src/index.css` — дизайн-система на Tailwind v4 (токены, анимации, glass-эффекты).

## Демо-сценарии

1. **Работник**: Главная → миссия дня → 3 рекомендации ИИ → «Откликнуться с письмом» → «Мои отклики» (видна воронка) → «Тренировка собеседования» (ответы с оценкой ИИ).
2. **Работодатель**: Обзор найма → воронка → «Кандидаты и ИИ-отбор» → «К собеседованию» → «Досье ИИ».
3. **Администратор**: Обзор → «Рынок труда» (дефицит профессий, регионы, динамика) → «Программы» → «Модерация».
